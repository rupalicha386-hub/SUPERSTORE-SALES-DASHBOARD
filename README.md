## 🚀 Project Overview

The **Superstore Sales Dashboard** is an interactive data analytics project developed using Microsoft Power BI.

The main objective is to analyze Superstore business data and understand sales, profit, quantity, and discount performance through interactive dashboards, KPI cards, charts, and visualizations.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| 📊 Power BI Desktop | Dashboard Development |
| 🔄 Power Query | Data Cleaning & Transformation |
| 📁 Excel / CSV | Dataset |
| 📈 Data Visualization | Business Analysis |

## 📌 Dashboard Pages

### 🔴 1. Superstore Sales Dashboard

This dashboard provides an overview of overall business performance.

### 💳 Key Performance Indicators (KPIs)

| KPI Card | Description |
|---|---|
| 💰 Total Sales | Overall sales amount |
| 📈 Total Profit | Overall profit |
| 📦 Total Quantity | Total quantity sold |
| 🏷️ Average Discount | Average discount |

### 📊 Charts & Visualizations

| Chart | Analysis |
|---|---|
| 📊 Sales by Category | Category-wise sales comparison |
| 📈 Profit by Region | Region-wise profit comparison |

### 🎛️ Interactive Slicers

- 🌍 Region
- 📂 Category
- 🚚 Ship Mode

These slicers allow users to interact with the dashboard and filter the data.
